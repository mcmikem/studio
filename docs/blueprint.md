# **App Name**: Omuto Central

## Core Features:

- User Role Management: Assign different access levels based on roles: Program/Partnership Manager, Operations, Media, Resource Mobilization, ED, Intern, Volunteer.
- Centralized Dashboard: Consolidated view of program stats, partnership details, financial status, and team activity.
- Strategic Plan Visualization: Dashboards that pull info to allow staff to monitor progress against objectives from strategic plans such as the October 2025 Operational Plan
- Customizable Form Templates: Design input forms tailored to Omuto's operational templates with automated data submission to a centralized database and Google Sheets.
- Impact Story Generator: Leverage the LLM tool to generate impactful narratives using the data gathered about activities for social media and Omuto Pulse, enhancing resource mobilization.
- Automated Reporting: Automatically generate weekly, monthly, and quarterly reports based on the data from the input forms. Also includes tracking budget spending
- Activity ROI Calculation: A feature to calculate the return on investment for different activities such as the Tree Planting activity, with all the key areas, e.g Basic Cost and ROI multipliers being activated, as a way to measure the value of impact created.

## Style Guidelines:

- Primary color: Use a vibrant red-orange (#FF6B35) inspired by the Omuto Foundation logo, symbolizing youthfulness and sustainable change.
- Background color: Use a light grey (#F0F0F0) to provide a clean and modern feel, ensuring readability and focus on the content.
- Accent color: Employ a complementary blue (#3591FF) to highlight key interactive elements, indicating areas that need user attention and adding visual contrast.
- Headline font: Use 'Space Grotesk' (sans-serif) for headlines to convey a techy, innovative, modern and clear tone, improving the professional and avant-garde style of the app.
- Body font: Use 'Inter' (sans-serif) for the body to ensure legibility across different screen sizes.
- Consistent and clear icons to represent different programs, team roles, and data categories. Icons should follow a minimalist style.
- Responsive layout that adapts to different screen sizes (desktops, tablets, and mobile devices) with a clear information architecture for easy navigation.
